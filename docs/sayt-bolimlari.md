# Veb-sayt bo'limlari katalogi

**Loyiha:** Shaxsiy portfolio + blog
**Soha:** IT / Dasturchi
**Tillar:** O'zbek + Ingliz (til almashtirish bilan)
**Uslub:** Zamonaviy minimal
**Texnologiya:** Next.js (React)

---

## Qanday ishlatiladi

Har bir bo'limning **kodi** bor (masalan `A1`, `C3`). Menga kodlarni yozib yuboring, men faqat o'shalarni quraman.

- Yozish namunasi: `A1, A2, B1, B3, C1, C2, D1, G1, G2`
- Yoki: **"Standart to'plam"** / **"To'liq to'plam"** deb yozsangiz, tayyor ro'yxatni olaman
- Yoki: **"hammasi"** — 45 ta bo'limning barchasi

**Belgilar:**
- ⭐ — yuqori ta'sir, portfolio uchun deyarli majburiy
- ✅ — tavsiya etilgan
- 🔧 — texnik/infratuzilma bo'limi (ko'rinmaydi, lekin saytni professional qiladi)
